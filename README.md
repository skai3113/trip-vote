# 8·20 海边旅行投票网站 v2
多人在线实时投票，包含：
- 8个候选海滨目的地及简要情报卡
- 每地：特色、预算、长沙出发难度、人流、海景、消费、推荐天数、优缺点、一句话总结
- 其他目的地自由推荐
- 正式投票：目的地、天数、预算、玩法、不能接受因素
- “不考虑价格最想去哪”梦想目的地投票
- Socket.IO 实时同步
- JSON 持久化
- 管理员 reset 接口

## 本地
Node.js 18+
npm install
node server.js
浏览器：http://localhost:3000

## 公网部署
需要部署到支持 Node.js + Socket.IO 的服务。若使用临时文件系统，votes.json 会在重启时丢失，正式长期使用建议接 PostgreSQL/Supabase/Firebase。

环境变量：
PORT
ADMIN_KEY

## 注意
当前为非正式朋友投票，不做登录/防刷票。正式使用可继续加入匿名唯一ID、截止时间、管理员后台、防重复投票等。
